Pesquisa na web

Em Auto, perguntas públicas podem consultar a web quando aplicável. Desligada evita pesquisas automáticas; você ainda pode pedir uma busca ou enviar um site. Apenas a consulta necessária é enviada, sem histórico, perfil, memórias ou tokens. A escolha Auto/Desligada fica neste dispositivo.

Aparência

Cores neutras, com transparência discreta nos controles. Essas escolhas visuais ficam apenas neste dispositivo.

Voz no seu dispositivo

Somente vozes identificadas como locais são usadas. O modelo continua no servidor.

Reconhecimento de fala local ainda não foi instalado. Nenhum microfone é capturado.

Seus dados, sob seu controle

Em Auto ou quando você pede uma pesquisa, a consulta usa o RSS público do Bing para uso pessoal e páginas públicas são lidas pelo servidor; os sites recebem o IP do servidor. Histórico, perfil, memórias e tokens não acompanham a pesquisa. O feed é usado apenas para mostrar links ao proprietário; o resumo usa as páginas públicas lidas separadamente. O resumo usa o modelo local. Sites bloqueados, logins e CAPTCHAs não são contornados.

Histórico, tarefas e memórias ficam no SQLite do servidor. A memória permanente só recebe o que você salva explicitamente.

Exportações contêm dados privados. O token não é salvo no armazenamento do navegador; Sair revoga a sessão atual.
